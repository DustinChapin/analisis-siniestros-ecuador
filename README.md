# analisis-siniestros-ecuador
Proyecto de Inteligencia de Negocios: Minería de Datos y Machine Learning aplicado a siniestros viales.

🚗 Análisis Predictivo de Siniestros de Tránsito en Ecuador
Proyecto de Inteligencia de Negocios desarrollado en la Universidad Técnica de Machala, enfocado en descubrir patrones de accidentabilidad vial y predecir la gravedad de los siniestros mediante Machine Learning.

📌 Tecnologías Utilizadas
Lenguaje: Python 3

Análisis y Manipulación: Pandas, NumPy

Visualización: Matplotlib, Seaborn, Plotly, Dash (Dashboard interactivo)

Machine Learning: Scikit-Learn (Decision Trees, Logistic Regression)

📊 Flujo del Proyecto
Minería de Datos: Preprocesamiento de la base de datos oficial del INEC, limpieza de valores nulos y recodificación de variables geográficas y temporales.

Análisis Exploratorio (EDA): Identificación de zonas críticas mediante tasas poblacionales normalizadas y mapas de árbol (Treemaps).

Modelado Predictivo: Entrenamiento de un Árbol de Decisión y Regresión Logística para predecir si un accidente resultará en "Daños Materiales" o "Con Víctimas", alcanzando un Accuracy del 66.5%.

🚀 Resultados Clave
La Hora del día representa más del 70% de importancia predictiva en la severidad de un siniestro.

Las zonas rurales, a pesar de tener menor volumen total de accidentes, presentan una tasa de letalidad y víctimas significativamente mayor que las zonas urbanas.
